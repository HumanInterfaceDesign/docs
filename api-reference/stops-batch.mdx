Resolves many stops at once. Pass a comma-separated `ids` list (for example `A27,L06,308214`) to hydrate a saved-stops list or a map viewport without one request per ID.

The response preserves one result per requested ID, in order: `{ requestedId, found, stop?, servedRoutes? }`. When `found` is `false`, the ID didn't resolve. Set `includeRoutes=true` to attach `servedRoutes` for each resolved stop. For nearby/geo search, use the [Stops reference](/api-reference/stops).

### SDK

```typescript
const results = await mta.stops.byIds({
  ids: ['A27', 'L06', '308214'],
  includeRoutes: true,
})

for (const result of results) {
  if (result.found) console.log(result.stop.name)
  else console.log(`${result.requestedId} not found`)
}
```
